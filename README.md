# 📚 Bulky Bookstore

Bulky is a fully functional **ASP.NET Core MVC e-commerce application** designed for selling books.  
It provides a complete online shopping experience with user roles, secure payments, order management, and shipment tracking.

---

## 🚀 Features
- ✅ **User Authentication & Authorization** with ASP.NET Core Identity  
- ✅ **Role Management**  
  - Customer  
  - Company  
  - Admin  
- ✅ **Product Management** (Books)  
- ✅ **Shopping Cart** with session support  
- ✅ **Payment Integration** (Stripe or Cash on Delivery)  
- ✅ **Discounts and Coupons**  
- ✅ **Order Processing** → From cart → Checkout → Order Confirmation → Shipment  
- ✅ **Unit of Work & Repository Pattern**  
- ✅ **Entity Framework Core** for database management  
- ✅ **Responsive UI** with Bootstrap  

---

## 🛠️ Technologies Used
- ASP.NET Core MVC  
- Entity Framework Core  
- SQL Server  
- ASP.NET Identity  
- Stripe Payment Gateway  
- Bootstrap  

---

## 📦 Project Structure
- **Bulky.Models** → Entity models  
- **Bulky.DataAccess** → Database context, repository, and DbInitializer  
- **Bulky.Utility** → Helpers and constants  
- **BulkyWeb** → MVC application (Controllers, Views, wwwroot)
